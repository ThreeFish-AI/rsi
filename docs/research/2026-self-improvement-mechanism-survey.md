**证据质量声明**：[7]–[12] 均读 HTML 全文；Awesome list 正文论文表由 JS 动态加载，静态抓取为空，改从其 GitHub `README.md` 与 `papers.json` 取全量分类，条目深读程度为「标题 + 章节归属级」，另抽读 3 篇代表作摘要（Phantom Guardrails arXiv:2607.13083、SkillsVote arXiv:2605.18401、Who Maintains Agent Skills? arXiv:2609.05677）。互证矩阵的勾选以 [7]–[12] 全文精读的章节级证据为准，Awesome 条目仅标题级、只参与「统计死区 + 最小样本」与「可证伪预测 + 回验」两行；[12] 节内转引的 Lin et al. 等二手引述按博文章节定位、不按原论文小节定位。

**交叉验证法**：候选机制须 ≥2 篇**独立**材料互证方可入选协议判据（避免把单篇论文的特定设定误当领域共识）；单源机制一律留路线图。rsi 现状对照以协议当前版（G0–G4、六态状态机、八镜头审阅）为基线。

**rsi 在 [8][11] 分类学中的定位**：以「skill/规约文本」为演化对象（[8] §3.3 一支）、post-task 时序（[11] v1 §4.1 Evolving Time）、outcome + environmental + 人审混合证据驱动（[11] v1 §4.2 Evolving Evidence）、带完整验证与人工闸门的系统；[11] 的章节号均按 arXiv:2608.03392v1 目录（v4 已重排章节，开放问题挪至 §10）；其 [11] v1 §6 开放问题清单（feedback reliability、benchmark overfitting、stale/redundant 退化、safety）与 rsi 的门禁体系逐项对得上——本次引入的机制全部落在该清单指出的缺口上。
